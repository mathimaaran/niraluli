Niraluli நிரலுளி

A Go-inspired programming language with semantic Tamil keywords, a Go-hosted compiler, and a C/Linux backend.

நிரலுளி joins நிரல் (program) and உளி (chisel): a tool for carving programs.

ExperimentalUTF-8LinuxC backendSQL / SQLiteFilesTimeFormattingApache-2.0

Project status Niraluli is an experimental research compiler, not a production language. v0.72 is implemented end to end on Linux through generated C. The planned native NASM backend has not started. Licensed under Apache License 2.0.

What is new in v0.72

  • Generic methods: methods on generic types with receivers like (b பெட்டி[யா]).
  • Monomorphization: each Name[T] instantiation gets its own method implementations.
  • Corpus: பொதுவகை_முறை.uli.

Prior highlight: generic types and union constraints in v0.71.
