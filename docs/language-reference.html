Lexical rules

Source and identifiers

Niraluli source is UTF-8 and uses the .uli extension. Identifiers begin with a Unicode letter or underscore and continue with letters, decimal digits, Unicode combining marks, or underscore. Tamil and Latin identifiers are both valid.

தொடக்கம் is the conventional entry package/function name, not a reserved keyword.

Literals

  • Decimal integers: 42 or Tamil digits such as ௪௨.
  • Floating point: 3.14 (மிதவைஎண், C double).
  • Strings: UTF-8 text in double quotes. Escapes include \n, \r, \t, \\, and \".
  • Boolean: மெய் and பொய்.
  • Nil: இன்மை in typed pointer/map/channel contexts.

Comments and semicolons

// line comment
/* block comment */

Semicolons are inserted at line endings using Go-like rules. Explicit semicolons remain valid and are required between the three clauses of a C-style சுழல்.

Variables, constants, and assignment

மாறி எண்ணிக்கை முழுஎண்
மாறி பெயர் சரம் = "நிரலுளி"
வயது := 1

மாறிலி அதிகம் முழுஎண் = 10
மாறிலி (
    பூஜ்ஜியம் = iota
    ஒன்று
)

எண்ணிக்கை = 10
அ, ஆ = ஆ, அ

:= infers types and must introduce at least one new name in its scope. Parallel assignment evaluates right-hand values before assignment. Multiple-return calls unpack through := or =.

மாறிலி declares compile-time constants (package or block scope). The initializer must be a constant expression; assigning to a constant is an error. Parenthesized groups support multiple specs; within a group, iota counts 0, 1, 2, … and omitted RHS/type repeat the previous spec.

Package-level மாறி (Tamil-0.70) declares variables at file scope with optional = init. Without an initializer the variable is zero-initialized; explicit initializers run before தொடக்கம் via a generated init hook. Prefix வெளி to export a package variable.

The blank identifier _ discards values:

மதிப்பு, _ := கணக்கு()
_, _ = வலை.எழுது(இணைப்பு, தரவு)

Control flow

If

எனில் x > 0 {
    பதிப்பி("positive")
} இல்லையேல் எனில் x < 0 {
    பதிப்பி("negative")
} இல்லையேல் {
    பதிப்பி("zero")
}

An optional initialization statement is scoped to the condition and branches:

எனில் மதிப்பு := கணக்கு(); மதிப்பு > 10 {
    பதிப்பி(மதிப்பு)
}

Loops

சுழல் i := 0; i < 10; i = i + 1 {
    எனில் i == 3 { தொடர் }
    எனில் i == 8 { முறி }
}

சுழல் நிபந்தனை {
    // while-like
}

சுழல் {
    // infinite
}

சுழல் i, value := ஒவ்வொரு values {
    பதிப்பி(value)
}

Range works over arrays, slices, strings, maps, and channels. Channel range receives until close.

Switch

திசைவி x {
எனில் 1, 2 {
    பதிப்பி("small")
}
எனில் 3 {
    பதிப்பி("three")
}
மற்றபடி {
    பதிப்பி("other")
}
}

There is no fallthrough. A tagless switch treats cases as boolean conditions. Like எனில், switch accepts an optional initialization statement.

Functions and return values

செயல்பாடு கூட்டு(அ முழுஎண், ஆ முழுஎண்) முழுஎண் {
    திருப்பு அ + ஆ
}

செயல்பாடு வகுத்தல்(அ முழுஎண், ஆ முழுஎண்) (முழுஎண், முழுஎண்) {
    திருப்பு அ / ஆ, அ % ஆ

Named results become initialized locals and support a naked return:

செயல்பாடு வகுத்தல்(அ முழுஎண், ஆ முழுஎண்) (ஈவு முழுஎண், மீதி முழுஎண்) {

Structs, pointers, and methods

வகை புள்ளி அமைப்பு {
    வெளி x முழுஎண்
    வெளி y முழுஎண்
}

செயல்பாடு (ப புள்ளி) கூட்டல்() முழுஎண் {
    திருப்பு ப.x + ப.y
}

செயல்பாடு (ப *புள்ளி) நகர்த்து(dx முழுஎண், dy முழுஎண்) {
    ப.x = ப.x + dx
    ப.y = ப.y + dy
}

Construct values positionally or with keyed fields:

அ := புள்ளி{3, 4}
ஆ := புள்ளி{x: 10, y: 20}
ஆ.நகர்த்து(1, 2)

Address and dereference use &x and *p. Field/method selection auto-dereferences struct pointers where appropriate. Value-method receivers copy; pointer receivers mutate addressable values.

Structs and arrays compare with ==/!= only if every member is comparable. Slices, maps, channels, and function values prevent aggregate comparability.

Arrays, slices, and maps

Arrays and slices

நிலையான := [3]முழுஎண்{1, 2, 3}
எண்கள் := []முழுஎண்{1, 2, 3}
எண்கள் = சேர்(எண்கள், 4, 5)

இடம் := ஆக்கு([]இருமி8, 128)
நகலானது := நகல்(இடம், மூலம்)
பதிப்பி(நீளம்(எண்கள்))
பதிப்பி(திறன்(எண்கள்))
  • Arrays are values with fixed length.
  • Slices share backing storage. Two-index slicing adjusts length; three-index slicing also limits capacity.
  • சேர் may allocate and returns the resulting slice; assign its result.
  • ஆக்கு([]T, len, cap) creates zeroed storage.

Maps

ம := அகராதி[சரம்]முழுஎண்{"அ": 1, "ஆ": 2}
ம["இ"] = 3
மதிப்பு, உண்டு := ம["அ"]
நீக்கு(ம, "ஆ")

சுழல் விசை, மதிப்பு := ஒவ்வொரு ம {
    பதிப்பி(விசை)
}
  • Map zero value is இன்மை; use ஆக்கு(அகராதி[K]V) or a literal before assignment.
  • Missing lookup yields the value type's zero value; comma-ok reports presence.
  • Keys must be comparable: scalars, pointers, and comparable arrays/structs are supported.
  • Maps compare only with இன்மை, not with each other.

Function values, closures, and defer

வகை மாற்றி = செயல்பாடு(முழுஎண்) முழுஎண்

இரட்டி := செயல்பாடு(எ முழுஎண்) முழுஎண் {
    திருப்பு எ * 2
}

மாறிகள் := []மாற்றி{இரட்டி}
பதிப்பி(மாறிகள்[0](21))

Package functions, bound methods, unbound method expressions, and closures are first-class values. Closures capture free variables by reference. Function values may be fields in structs or elements in slices.

காட்டு := பொருள்.காட்டு       // bound method value
காட்டு()

செயல் := வகை.முறை           // unbound method expression
செயல்(பெறுநர், வாதம்)

தள்ளிவை schedules calls in LIFO order when the surrounding function returns. Arguments are evaluated immediately:

தள்ளிவை வளம்.மூடு()
தள்ளிவை முடிந்தது    // zero-argument sugar for முடிந்தது()

Generics

வகை பெட்டி[யா] அமைப்பு { val யா }
வகை எண்[டி முழுஎண் | சரம்] அமைப்பு { x டி }

செயல்பாடு (b பெட்டி[யா]) பெறு() யா { திருப்பு b.val }
செயல்பாடு (b *பெட்டி[யா]) வை(v யா) { b.val = v }

செயல்பாடு அடையாளம்[யா](x யா) யா { திருப்பு x }
செயல்பாடு தலை[யா](xs []யா) யா { திருப்பு xs[0] }

a := பெட்டி[முழுஎண்]{val: 42}
எண் := அடையாளம்(42)
பெயர் := அடையாளம்[சரம்]("நிரலுளி")

Function and type generics use type parameters in square brackets. Constraints may be omitted or written as எதுவும் (any), or as a union of concrete types (முழுஎண் | சரம்). Calls infer type arguments or accept explicit f[T](…). Generic structs and defined types instantiate as Name[T]{…}. Methods on generic types use the type's parameters in the receiver ((b பெட்டி[யா])), not method-level [T]; each instantiation gets monomorphized methods. The C backend monomorphizes each instantiation. Interface constraints are not implemented.

Packages and visibility

தொகுப்பு பயன்பாடு

கொணர் வ "வலை"
கொணர் _ "side-effects"

வெளி வகை அமைவு அமைப்பு {
    வெளி பெயர் சரம்
    மறைவு முழுஎண்
}
  • All files in one package use the same package name.
  • Imports resolve by directory; imported calls use a qualifier.
  • Unused non-blank imports are errors. Import cycles report their path.
  • Top-level functions/types/constants/variables and struct fields require வெளி for access by another package.
  • Final function parameters may be variadic (...T); the final call argument may be slice... (Tamil-0.69).
  • Compiler packages "வலை", "பரிமாற்றம்", "தரவுத்தளம்", "கோப்பு", "நேரம்", and "வடிவம்" resolve from stdlib/. See the standard library reference.
