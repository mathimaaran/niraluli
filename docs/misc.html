Tamil typing for Niraluli

Niraluli keywords and identifiers use Tamil Unicode (UTF-8). Developers should learn a real Tamil keyboard layout rather than English-to-Tamil phonetic transliteration.

No phonetic input Phonetic / romanized tools (type vanakkam → get வணக்கம்) are convenient for casual chat, but they hide the script and produce weaker muscle memory for Niraluli keywords. Prefer Tamil99, Inscript, or Bamini practice below.

Also install a Tamil-capable font such as Noto Sans Tamil so editors and terminals render glyphs correctly. See notes/fonts-tamil.md and Getting started → Tamil editor setup.

Recommended layouts

Layout Why it matters Best for Niraluli?
Tamil99 Official Tamil Nadu keyboard standard. Logical consonant→vowel typing on a normal QWERTY board. Strong Unicode support via Keyman and OS input methods. Yes — first recommendation
Inscript Government of India standard shared across Indian scripts. Once learned, transfers to other Indic languages. Built into many OS Tamil keyboards. Yes — especially if you already know Inscript
Bamini Popular in Tamil typing exams and publishing workflows. Many free online tutors teach it. Historically tied to non-Unicode fonts in some tools—prefer Unicode-aware practice for Niraluli source. Useful for speed drills; keep files UTF-8

OS / editor setup tips

  • Prefer Unicode layouts (Tamil99 or Inscript) for Niraluli. Save every .uli file as UTF-8.
  • Linux: install Keyman Tamil99, or enable Tamil input methods from your desktop’s language settings when available.
  • Windows / macOS: add Tamil language support, then choose Tamil99 or Inscript; Keyman works well cross-platform.
  • Editor: configure a Tamil font fallback (Noto Sans Tamil / Noto Sans Tamil UI) so keywords and identifiers are readable. Details live in notes/fonts-tamil.md.
  • Switching: learn one OS shortcut to flip between English and Tamil so Latin operators (:=, {}, ()) stay easy while keywords stay Tamil.

Suggested practice plan

  1. Install Keyman Tamil99 (or OS Inscript if you already use it).
  2. Spend a few sessions on vowels, consonants, and pulli (்) until common Niraluli keywords feel automatic: தொகுப்பு, செயல்பாடு, எனில், திருப்பு, பதிப்பி.
  3. Use TypingBit / MaxTyping / Baba Typing for timed accuracy, not as the only input method.
  4. Rewrite small corpus examples by hand (for example corpus/tamil/வணக்கம்.uli) without copy-paste.
  5. Only after Unicode layout fluency, optionally use Bamini drills for raw speed—then return to Tamil99/Inscript for coding.
Goal for Niraluli contributors Be able to type a short program’s Tamil keywords and identifiers from memory in Unicode, with Latin punctuation for operators and braces.
